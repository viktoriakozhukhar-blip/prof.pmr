📊 Практическая часть исследования

Результаты прохождения теста автоматически сохраняются в базе исследования.

Как работает исследование:

Участник указывает город и возраст → проходит профориентационный тест → получает индивидуальный результат → данные автоматически попадают в Google Таблицу.

После накопления ответов данные можно использовать для построения диаграмм и анализа профессиональных предпочтений молодежи ПМР.
